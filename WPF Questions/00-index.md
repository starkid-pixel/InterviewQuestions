## Suggested study order

Start with Chapters 1–4 to understand WPF's object, property, tree, and binding model. Then study Commands/MVVM, templates/resources, threading/async, collections/virtualization, and finally advanced internals, custom controls, performance, and scenario questions.

## Interview focus

For senior interviews, prioritize:

- Dependency Property value precedence
- DataContext and binding resolution
- Logical vs visual tree
- Measure/Arrange/render
- Dispatcher and thread affinity
- async/await and UI deadlocks
- ICommand and CanExecuteChanged
- ICollectionView
- UI/data virtualization
- WPF memory leaks
- performance diagnosis
- UserControl vs Custom Control
- Generic.xaml and DefaultStyleKey
- MVVM boundaries and testability
