# Modular Monitoring App

WPF/.NET 8 interview reference solution.

## Concepts
- MVVM
- DI / Generic Host
- Modular navigation
- Navigation lifecycle
- Streaming with IAsyncEnumerable
- Bounded Channel<T>
- Batching and throttled UI updates
- Event bus
- Paging + cancellation
- Page cache
- UI virtualization

Open `ModularMonitoringApp.sln` with Visual Studio 2022+.
Restore NuGet packages and run the WPF project.
